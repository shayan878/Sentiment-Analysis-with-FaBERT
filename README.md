

## What is included

The code is separated into:

- `src/data/` — CSV loading, label normalization, train/validation splitting, tokenization, TensorDatasets and DataLoaders.
- `src/augmentation/` — Persian back-translation and saving augmented sentences.
- `src/models/` — FaBERT classifier architecture and fine-tuning setup.
- `src/training/` — reusable training and evaluation loops.
- `src/evaluation/` — accuracy, macro-F1 and confusion matrix calculation.
- `src/visualization/` — class distribution, training curves and confusion matrix plots.
- `src/config.py` — model/data/training configuration.
- `main.py` — entry point that runs the original-data and augmented-data experiments.

## Expected data

Place these files under `data/`:

```text
data/
├── original.csv
├── test.csv
└── sentences_dataframe.csv
```

`original.csv` and `test.csv` use the first column as text and the second column as labels, matching the notebook.

`s​​entences_dataframe.csv` contains the `Sentences` column generated by back-translation.

## Run

```bash
pip install -r requirements.txt
python main.py
```

## Back-translation

The original notebook generated back-translated sentences and wrote them to:

```text
data/sentences_dataframe.csv
```

The reusable implementation is in:

```text
src/augmentation/backtranslation.py
```

You can call `generate_and_save(...)` to regenerate that file before training.

## Notes

The notebook trained two equivalent classifier definitions, `fa_BERT` and `fa_BERT2`. Since their architectures were identical, this version uses one reusable `FaBERTClassifier` and runs it twice: once on the original split and once on the back-translated split.

The original notebook relied on Kaggle paths. These codes version replaces those with project-relative paths so it can be run locally or from a GitHub clone.
